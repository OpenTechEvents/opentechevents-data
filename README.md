# OpenTechEvents Data

> Archived proof of concept.

This repository was an early proof of concept for aggregating event sources, normalizing them to OTE, and publishing reusable feeds.

It helped validate ideas for the OpenTechEvents specification and informed early tooling for aggregators and data consumers. It is not intended to become a canonical event directory or a user-facing events platform.

OpenTechEvents is focused on enabling many independent tools, directories, calendars and aggregators to interoperate through an open specification.

For current information, see:

- Website: https://opentechevents.org/
- Specification: https://github.com/OpenTechEvents/opentechevents-spec
- Tools: https://github.com/OpenTechEvents/ote-tools
- Discussions: https://github.com/OpenTechEvents/opentechevents-spec/discussions
